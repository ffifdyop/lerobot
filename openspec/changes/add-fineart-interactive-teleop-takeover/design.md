## Context

`RolloutController` 已负责交互会话、运行段取消和启动前规划；base 策略负责逐帧发送动作。RTC 已能使旧动作与在途推理失效。SO 主臂支持位置反馈和力矩开关，但 DAgger 只在暂停时对齐，不能直接满足持续跟随需求。

## Goals / Non-Goals

**Goals:** 在当前 FineART base 交互会话内完成策略、人工、策略的循环，策略控制期间主臂持续跟随从臂实测位置，恢复后继续同一整体任务。

**Non-Goals:** 不改 DAgger，不录制人工数据，不扩展到异构遥操作映射或远程推理，不保证零延迟或未经真机验证的物理连续性。

## Decisions

### 接入现有控制器

采用可选 `takeover` 配置，限定交互式 base 和本地 RTC/sync。控制器接受 `/teleop` 与 `/resume`，硬件读写始终由控制线程执行。接管请求结束当前策略运行段；人工模式运行独立的遥操作循环，恢复时再进入策略运行段。保留 `/reset` 回初始姿态、`/stop` 结束会话的语义。

没有采用 DAgger 策略：它依赖数据集，且不满足当前交互段和自动 subtask 的生命周期。

### 主臂跟随实测位置

新增小型主从臂协调组件，验证主臂具备反馈和力矩控制、主从臂关节键完全匹配、位置数值有效；SO 配置的 `use_degrees` 必须一致。启用功能时要求从臂具备位置保持能力。

启动策略前，先将主臂目标设为其当前位置，再使能力矩，以可取消的插值逐步对齐到从臂实测位置。对齐后，策略和启动规划的每个控制 tick 将新采集的从臂位置发送给主臂。使用实测位置可以反映跟踪滞后和驱动限幅，不直接镜像策略预测目标。

### 接管与恢复

接管立即撤销当前推理和规划，保留控制器持有的整体目标。控制线程保持从臂，持续同步主臂，直至所有关节误差均不超过配置阈值，才关闭主臂力矩并允许人工动作发送。对齐超时则留在保持状态，报告拒绝接管，用户可以重试或停止。

人工模式复用 teleop 和 robot action processors，按配置控制频率发送动作，不向策略发布观测、不运行 autosteer。恢复时停止人工动作，清空策略队列、插值和旧规划历史，重新对齐主臂，使用新画面生成首个 subtask，然后恢复动作。若没有整体目标，则使用当前手工 subtask 恢复。

### 空格快捷键与命令共存

沿用唯一的 stdin 监听器。启用 takeover 且输入为 POSIX TTY 时，使用 cbreak 模式读取字符，空输入行上的空格立即调用当前状态对应的 `/teleop` 或 `/resume`。输入文字命令时，空格是命令参数的一部分；支持退格和清空当前行，保留 Ctrl-C 信号。停止、EOF 和输入异常时恢复终端设置。管道和非 TTY 输入继续使用原来的逐行命令，不从普通空格推断硬件操作。

切换由控制器在同一把控制锁下判断状态。接管等待期间、恢复等待期间忽略重复切换，已排队的恢复不能被同一轮按键反转。TTY 没有按键释放事件，因此以连续空格之间至少 0.75 秒的间隔抑制常见长按连发；说明要求短按。启动规划期间仍可再次请求接管。

### 生命周期和竞争

重置与停止取消待处理的接管和恢复；启动规划期间也可以接管。动作发送边界在推理前后检查运行段取消事件，避免 sync 模型返回后发送已取消运行段的动作。正在进行的一次设备 I/O 或同步模型调用不能被强制中断，人工模式必须等控制线程接手后才对外宣布就绪。

遥操作或反馈 I/O 失败结束会话并保持现有故障报告路径；退出时释放主臂力矩。接管会话故障时跳过自动回初始姿态，正常停止仍遵守原有返回设置。保持、停止及取消路径不自动恢复策略。

## Risks / Trade-offs

- 串口反馈增加每个控制 tick 的开销 → 用现有 cadence 报告观察，真机确认能否达到设定频率；不新增后台硬件写线程。
- 标定误差、跟踪延迟或负载会导致实际位置差异 → 在人工启用前检查误差，阈值使用机器人位置接口单位（归一化关节或度，夹爪 0–100）。
- 同步推理会阻塞控制线程 → 文档注明响应边界，当前脚本继续默认 RTC。
- 启用和关闭主臂力矩会改变手感 → 用明确状态消息告知当前控制权，保留真机验证项。

## Migration Plan

库配置默认关闭此功能。本机 `rollout.sh` 默认开启，并沿用 `~/Dev/Manipulation/lerobot/teleoperate.sh` 的 `bimanual_follower` / `bimanual_leader` 标定 ID、四条 `/dev/serial/by-id/` 串口和 `use_degrees=false`。使用现有标定目录规则读取两侧标定，不复制或重建标定文件。所有脚本硬件默认值均可通过环境变量覆盖，`TELEOP_TAKEOVER=0` 关闭接管。先运行配置检查和 mock 回归，再由用户进行真机验证。

## Open Questions

主臂串口和标定 ID 已按参考脚本配置。实际可接受的关节误差和控制频率仍需真机验证；它们不阻塞接口实现和无硬件测试。
